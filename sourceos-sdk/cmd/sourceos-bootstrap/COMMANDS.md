# sourceos-bootstrap commands

## Deterministic (canonical)
- `doctor`
- `login`
- `build`
- `fetch`
- `write`
- `info`
- `audit`
- `validate`
- `verify`

## Agent overlay (non-canonical)
- `ask`
- `plan`
- `agent run`
- `mcp serve`
- `mcp doctor`

Overlay commands must delegate to deterministic tools and approval-gated execution.
